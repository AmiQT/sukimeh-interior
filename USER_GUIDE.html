Pengenalan Sistem

Sukimeh AI Interior Designer adalah platform reka dalaman berasaskan kecerdasan buatan (AI) yang membolehkan pelanggan Chin Hin Group memvisualisasikan susun atur perabot dalam ruang mereka, dan terus membeli produk yang disyorkan.

Cara Akses & Login

🌐 URL Akses

http://localhost:3000

Tiada login diperlukan — sistem boleh diakses terus melalui browser.

Browser disyorkan: Google Chrome, Microsoft Edge, atau Firefox versi terkini.
Pastikan JavaScript diaktifkan.

⚙️ Keperluan Server

Untuk fungsi penuh, dua server perlu berjalan serentak:

  • Frontend: cd frontend → npm run dev (port 3000)
  • Backend: cd backend → uvicorn main:app --reload --port 8000
Nota: Untuk demo tanpa backend, gunakan butang "Cuba Demo" — tidak memerlukan server backend.

Mod Demo membolehkan pengguna melihat keseluruhan fungsi sistem tanpa perlu upload floorplan. Data pratetap (mock data) dengan 3 bilik dan 12 item perabot dimuatkan secara automatik.

Halaman Layout (Canvas)

🖼️ Canvas Interaktif

Canvas menunjukkan susun atur perabot dalam ruang anda. Setiap item boleh dialih mengikut kedudukan yang dikehendaki.

  • Klik item — papar maklumat: nama, kedudukan, anotasi AI
  • Drag item — alih perabot ke kedudukan baru
  • Klik kawasan kosong — nyahpilih item

🏷️ Badge Skor

Skor keseluruhan layout dipaparkan di sudut kanan atas canvas (contoh: 98% Match). Skor dikira berdasarkan:

  • Ruang pergerakan (traffic flow)
  • Liputan cahaya & pengudaraan
  • Jarak optimum antara perabot
  • Liputan WiFi

🔘 Tab Sisi Kanan

WorkflowSenarai Smart Optimization — cadangan AI untuk ruang anda (Dead Zone Elimination, Traffic Flow, dll.)
ConnectivityPeta liputan WiFi 6E, senarai device (Router, Mesh Extender, Smart Sensor) & kekuatan isyarat

🏠 Panel Perabot (Bawah)

Filter perabot mengikut bilik menggunakan tab:

🏠 All Rooms 🍳 Kitchen 🛋️ Living Room 🛏️ Bedroom

Klik mana-mana item dalam senarai untuk highlight pada canvas.

Apabila terdapat item dalam troli, butang 🛒 X item — RM XX,XXX akan muncul di header kanan atas. Klik butang tersebut untuk membuka CartDrawer.

Kurang kuantitiKlik butang − (item dibuang jika kuantiti = 0)
Buang itemKlik ikon 🗑 merah pada item
Kosongkan troliKlik "Kosongkan troli" di bawah

CartDrawer memaparkan pengiraan automatik:

Kongsi Proposal

Fungsi "Kongsi 🔗" membolehkan anda berkongsi cadangan reka dalaman AI kepada rakan, ahli keluarga, atau jurujual Chin Hin.

Di halaman Shop, klik butang "Kongsi 🔗"
Link unik dijana secara automatik (contoh: /proposal/abc123)
Link disalin ke clipboard — toast notification akan muncul
Klik "Buka" dalam toast untuk pratonton halaman proposal
Kongsikan link kepada sesiapa — mereka boleh lihat reka bentuk & senarai produk
Nota: Fungsi Kongsi memerlukan backend server berjalan di port 8000.

Soalan Lazim (FAQ)

❓ S: Boleh ke guna tanpa upload gambar?

J: Ya. Klik "Cuba Demo" untuk terus ke demo penuh dengan data pratetap tanpa perlu upload sebarang gambar.

❓ S: Format gambar apa yang terbaik?

J: PNG atau JPG resolusi tinggi dengan pelan lantai yang jelas. Elakkan gambar yang terlalu gelap atau kabur.

❓ S: Boleh drag perabot ke mana-mana?

J: Ya, semua item dalam canvas boleh dialihkan secara bebas. Kedudukan baru disimpan dalam sesi semasa.

❓ S: Troli saya hilang selepas refresh?

J: Troli disimpan dalam session storage browser. Data akan kekal selagi tab browser tidak ditutup sepenuhnya.

❓ S: Boleh buat pesanan sebenar?

J: Ini adalah MVP demo. Integrasi penuh dengan sistem e-commerce Chin Hin akan dilakukan pada fasa seterusnya.
